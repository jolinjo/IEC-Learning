# 1. 前言

## 1.1 本手冊的定位：讓圖與實物對得起來

第一、二部手冊解決了「元件叫什麼」（-QA1）,第四部解決了「圖怎麼畫」。但拉開盤門,手上是一把導線：哪條是 L1？藍色的一定是中性線嗎？馬達端子上的 U1、W2 是什麼意思？這些「導體與端子的身分識別」就是 IEC 60445 的守備範圍。

它是圖面與實物之間的翻譯層：圖上寫 -X1:PE 接綠黃線、-MA1:U1 接第一相——設計者靠它決定「線上標什麼、用什麼顏色」,配線與維護的人靠它把圖上的一條線對應到手上的一條線。認錯線輕則燒設備,重則感電,所以 60445 被 IEC 列為基礎安全標準（basic safety publication）,各產品標準都要引用它。

## 1.2 沿革：60446 去哪了？

導體顏色規則原本是獨立的 IEC 60446,2010 年起併入 IEC 60445——現在「字母數字識別」與「顏色識別」都在 60445 一本裡。看到舊文件引用 60446 時,直接查現行 60445 即可,技術內容延續。

## 1.3 與 60204-1 的分工

| 標準 | 管什麼 | 例子 |
|---|---|---|
| IEC 60445 | 通用規則：導體代號怎麼寫、顏色的保留與禁用 | 綠黃雙色只能當 PE;N 用藍色 |
| IEC 60204-1 | 機械領域的加碼要求 | 例外迴路用橘色;控制迴路顏色慣例（第五部手冊） |

通則在 60445,機台的特殊要求在 60204-1;衝突時,產品標準（60204-1）優先於通用標準。

# 2. 導體的字母數字識別

## 2.1 交流系統

| 代號 | 導體 | 備註 |
|---|---|---|
| L1、L2、L3 | 三相的第 1、2、3 相 | 系統側（配電）的相線名 |
| N | 中性線 | 與藍色綁定（3.1 節） |
| 單相：L | 單相的相線 | 家用與控制電源常見 |

**※ **相序 L1→L2→L3 是「名字」不是「顏色」：換相（調相序）時改的是接線,不是把線重新標名。馬達正反轉的相序問題,圖上看 L 編號、實物看端子,不要看顏色猜。

## 2.2 直流系統

| 代號 | 導體 | 備註 |
|---|---|---|
| L+ | 正極 | 24 V DC 控制系統的 +24V |
| L− | 負極 | |
| M | 中間點導體 | 例如 ±24 V 系統的 0 V 中點;與藍色綁定 |

實務上 24 V 控制迴路常直接以電位名 +24V／0V 標示（第八部手冊的線號主題）,與 L+／M 的正式代號並存;專案內擇一貫徹並在圖例頁宣告。

## 2.3 保護導體與功能導體

| 代號 | 導體 | 意義 |
|---|---|---|
| PE | 保護導體（protective earth） | 安全接地——故障電流的回家路 |
| PEN | PE＋N 合一導體 | 舊式 TN-C 系統;機台內部原則上不用 |
| PEL／PEM | PE 與 L／M 合一 | 特殊系統,罕見 |
| FE | 功能接地（functional earth） | 為訊號品質、EMC 而接地,**不是**安全接地 |
| FB | 功能等電位連結 | 同上,功能性用途 |

**※ **PE 與 FE 的區分是審圖重點:示波器量測參考點、屏蔽層接地是 FE;人身安全靠 PE。FE 不得用綠黃雙色線（那是 PE 的專屬制服）,常見作法是用其他顏色並在圖上標 FE。

# 3. 導體的顏色識別

## 3.1 兩條鐵律：綠黃與藍

顏色規則很多,但真正「違反就是危險」的只有兩條,先背死：

1. **綠黃雙色＝保護導體（PE）專屬。**綠黃線不得作任何其他用途;PE 也不應用其他顏色。這是全球通則,沒有例外空間。

2. **藍色（建議淺藍）＝中性線 N／直流中間點 M。**迴路中沒有 N 時,藍色線可挪作他用（60204-1 允許,見第五部手冊）,但有 N 的系統中藍色只給 N。

## 3.2 相線的顏色

相線（L1／L2／L3）的顏色**不是全球統一**,60445 的立場是「除綠黃與藍以外的顏色皆可,建議黑、棕、灰」。歐洲固定配線的常見慣例：

| 導體 | 常見顏色（歐規慣例） |
|---|---|
| L1 | 棕 |
| L2 | 黑 |
| L3 | 灰 |
| N | 藍 |
| PE | 綠黃雙色 |

**※ **各國電工法規（及老舊裝置）差異很大——舊歐規曾用黑黑黑、日本用紅白黑、北美另有一套。跨國案子先查目的國法規;機台內部則以 60204-1 的規則為準（下一節）。**顏色永遠只是輔助,身分以線號與端子標示為準**——這是 60445 的核心精神。

## 3.3 機台配線的顏色慣例（60204-1 加碼）

機台盤內配線,60204-1 在 60445 之上加了一層慣例（詳見第五部手冊,此處速記）：

| 顏色 | 用途 |
|---|---|
| 黑 | 交直流動力迴路 |
| 紅 | 交流控制迴路 |
| 藍 | 直流控制迴路 |
| 橘 | 例外迴路——主開關切斷後仍帶電的導線（保命色!） |
| 綠黃 | PE（鐵律） |
| 淺藍 | N／M（鐵律） |

# 4. 設備端子的標示

導線有名字,線的兩端——設備上的端子——也有標準名字。

## 4.1 三相設備端子：U、V、W

三相設備（馬達、變壓器、驅動器輸出）的端子以 U、V、W 標示,對應接入的 L1、L2、L3：

| 端子 | 意義 |
|---|---|
| U1、V1、W1 | 三相繞組的頭端 |
| U2、V2、W2 | 三相繞組的尾端 |
| PE（含接地符號） | 保護接地端子 |

馬達接線盒裡六支端子（U1V1W1／U2V2W2）的短接方式決定 Y 或 Δ 接法：Y 接＝U2V2W2 短接成星點;Δ 接＝U1-W2、V1-U2、W1-V2 兩兩相連。看懂端子名,接線盒蓋內的接線圖就一目了然。

**※ **「系統側用 L,設備側用 U」是分辨圖面位置的線索:圖上一條線從 L1 走到 U1,就是「電源第 1 相進了設備第 1 端子」。

## 4.2 端子標示的通則

- 端子標示要**印在端子旁或元件本體**,持久可辨——標示消失的端子等於身分不明的線。

- 圖面上的端子代號**必須与實物印字一致**（61082-1 的要求,第四部手冊 2.4 節）:圖上寫 A1,元件上就是 A1。

- 端子排的端子以「端子排代號:端子號」引用,如 **-X1:5**（端子的系統性識別歸 IEC 61666,見第八部手冊）。

## 4.3 元件接點編號的業界慣例

接觸器、繼電器、按鈕上的 13-14、21-22 這套數字,嚴格說出自歐洲元件標準（EN 50011／50012 等）的慣例,不在 60445 正文,但它與 60445 的端子標示一起構成「看實物」的完整知識,整理如下：

| 端子對 | 意義 | 記法邏輯 |
|---|---|---|
| 1-2、3-4、5-6 | 主迴路接點（三相進出） | 單數＝進、偶數＝出 |
| A1-A2 | 線圈 | A1 接控制電源正／L |
| 13-14、23-24… | 輔助常開接點 | 十位數＝第幾組,個位 3-4＝常開 |
| 21-22、31-32… | 輔助常閉接點 | 個位 1-2＝常閉 |
| 95-96、97-98 | 過載繼電器的跳脫接點 | 95-96 常閉（跳脫斷開）、97-98 常開 |

**判讀口訣：個位數 1-2 常閉、3-4 常開;十位數是流水組號。**圖上接點旁的數字與實物端子印字一一對應,這就是 4.2 節「圖物一致」原則的日常展現。

# 5. 圖面與實物的對應

把本手冊與前六部串起來,一條線的完整身分鏈：

| 層次 | 識別 | 出處 |
|---|---|---|
| 這條線接到哪顆元件 | 參考代號 -QA2 | 81346-1／-2 |
| 接到元件的哪個點 | 端子代號 :A1 | 60445＋製造商 |
| 線本身叫什麼 | 導體代號／線號（L1、+24V、201…） | 60445＋61175（第八部） |
| 線是什麼顏色 | 顏色規則 | 60445＋60204-1 |
| 畫在圖的哪裡 | 座標／交互參照 | 61082-1 |

查線標準動作：圖上讀出「-QA2:A1,紅色,線號 105」→ 實物在 -QA2 的 A1 端子上找印著 105 的紅線。五個識別全對才算同一條線;顏色對但線號不對,優先相信線號（3.2 節精神）。

# 6. 實務情境範例

**情境一：盤內驗收抓錯。**驗收時發現某綠黃線一端接 PE 排、另一端接了 0V 端子——電工說「反正 0V 最後也接地」。判定：不合格。綠黃是 PE 專屬（3.1 鐵律）,0V 是功能導體,即使電位相同,身分不同;混用後維護者會誤判斷開綠黃線的後果。改用藍或其他色線,圖面標 M／0V。

**情境二：馬達反轉。**新機台馬達反轉。查圖：圖面 L1→U1、L2→V1、L3→W1 正確;查實物：盤內正確,馬達接線盒內 V1、W1 兩條線對調了——配線員憑顏色接線,而該電纜芯線顏色與盤內慣例不同。處置：依端子標示（不是顏色）改回,並在兩端補掛線號標籤（62491,第八部手冊）。教訓即 60445 核心精神:顏色是輔助,標示才是身分。

**情境三：老盤改造。**改造 20 年老盤,發現相線全黑、無線號。依 60445 現行規則整理：補掛線號標籤、PE 換綠黃線（或全長套綠黃標識）、有 N 的迴路確認藍色未被挪用、例外迴路換橘線並掛警告（60204-1）。改造的第一張交付文件就是「新舊線號對照表」。

# 7. 常見問答（FAQ）

### Q1：三相一定要棕黑灰嗎？

不是。60445 只禁止相線用綠黃與（有 N 系統中的）藍,棕黑灰是「建議＋歐洲慣例」。機台內部依 60204-1（動力黑、控制紅／藍）;固定配線依當地電工法規。

### Q2：藍色線可以拿來當控制線嗎？

看系統:迴路裡沒有中性線 N 時可以（60204-1 明文允許,且直流控制慣用藍）;有 N 的部分,藍色保留給 N。同一盤內兩種情形並存時,靠線號區分,圖例頁說明。

### Q3：PE 和 FE 接在同一支接地棒上,為什麼還要分？

因為「目的」不同：PE 是人身安全,斷了會出人命,受法規強制;FE 是訊號品質,斷了只是雜訊變大。分開標示,維護者才知道哪條線動不得。

### Q4：單相設備的端子怎麼標？

單相用 U1-U2(或製造商標 L-N)。加熱器等無極性負載常直接標 1-2。原則不變：圖與實物一致。

### Q5：L1/L2/L3 跟 R/S/T 是什麼關係？

R-S-T 是舊式（德規/日規）相線名,對應現行 L1-L2-L3;二次側舊名 U-V-W 現為設備端子名。看到 R/S/T 的圖,直接心譯成 L1/L2/L3 即可,新圖不要再用。
