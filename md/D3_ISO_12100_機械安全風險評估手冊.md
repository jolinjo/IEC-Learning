# 1. 前言

## 1.1 第十一部的定位:所有機械安全標準的「總目錄」

前面幾部手冊講的都是「某一件事怎麼做」:60204-1 講電氣設備、61439 講盤體。但在動手做這些之前,有一個更根本的問題沒人回答:**這台機器到底有哪些危險?要防到什麼程度才夠?**

ISO 12100 回答的就是這個問題。它不教你接線、不教你選護罩型號,它教你一套**方法論**:怎麼有系統地找出機器的危害、怎麼估計風險大小、怎麼按正確的順序把風險降下來。你可以把它想成一本旅遊指南的「總目錄」——它本身不帶你逛任何一個景點,但它告訴你有哪些景點、該用什麼順序逛、每個景點要看哪本分冊。

💡 白話比喻:12100 是「健康檢查的流程」,其他標準是「各科的治療方法」。健檢流程告訴你要檢查哪些項目、指數多高算異常;查出心臟有問題,才去翻心臟科的專書(例如電氣危害就翻 60204-1)。沒做健檢就直接吃藥,吃的可能根本不是你需要的藥。

==12100 是 A 類標準(基礎安全標準),60204-1、13849-1 這些 B 類標準都是它的「下位展開」——風險評估先做,才知道要用哪些 B/C 類標準、做到什麼等級。==

## 1.2 設計者什麼時候會用到 12100

| **時機** | **用 12100 做什麼** |
|---|---|
| 新機種開發 | 設計初期做完整風險評估,決定防護策略與安全等級 |
| 出口 CE 認證 | 機械指令要求的技術文件核心就是風險評估報告 |
| 改機、加裝置 | 改動後重新評估(見 7.2)——改機不評估是最常見的事故源 |
| 客戶驗收要求 | 越來越多客戶規範指名要附風險評估文件 |
| 事故後檢討 | 用同一套方法回頭檢查當初漏了哪個危害 |

## 1.3 版本與適用範圍

現行版本為 ISO 12100:2010,它把早期的 ISO 12100-1、12100-2 與 ISO 14121-1 三份文件合併成一本,此後內容穩定沿用至今——年份沿革知道這句就夠了。台灣對應標準為 CNS 上的機械安全一般設計原則,內容與 ISO 版一致。

適用範圍:**所有機械**。不分產業、不分大小,從輸送機到整條產線,設計階段的安全思考都從這本開始。

# 2. A/B/C 類標準體系

## 2.1 三個層級的分工

機械安全標準不是一本大全,而是一個「金字塔分工體系」。白話講:A 類是憲法、B 類是各領域的法律、C 類是特定行業的施行細則。

| **層級** | **性質** | **代表標準** | **管什麼** |
|---|---|---|---|
| A 類 | 基礎總則(方法論) | ISO 12100 | 風險評估與風險降低的流程——所有機器通用 |
| B1 類 | 共通「安全層面」 | ISO 13857(安全距離)、ISO 13849-1(控制系統功能安全) | 某一類安全議題的通用規則 |
| B2 類 | 共通「安全裝置」 | ISO 13850(急停)、ISO 14119(護罩聯鎖)、IEC 60204-1(電氣設備) | 某一類裝置或設備的通用要求 |
| C 類 | 特定機種 | 沖床、CNC 工具機、射出成型機、機器人各自的專屬標準 | 直接告訴你「這種機器」怎麼做 |

幾個常用 B 類標準的白話定位:

- **IEC 60204-1**(第五部手冊):機台電氣設備的安全基本功——主開關、感電防護、急停的電氣行為。
- **ISO 13849-1**:安全迴路的「可靠度等級」(PL)怎麼算——風險評估的結果決定要做到哪一級。
- **ISO 13850**:急停裝置的原則——紅蘑菇、拍下保持、復位不自動重啟的上位依據。
- **ISO 14119**:護罩聯鎖裝置——門開機停的安全開關(-BG)怎麼選、怎麼防人「騙過它」。
- **ISO 13857**:安全距離——護罩開孔多大、離危險點多遠,手才伸不進去。開孔越大要離越遠,這張表就在這本裡。

💡 怎麼記:遇到問題先問「這是哪一類的事」。「風險要評到多細」→ A 類;「光柵要裝多遠」→ B 類(13855/13857);「射出機的門要幾道聯鎖」→ C 類。

## 2.2 C 類優先原則

==同一件事若 C 類標準有規定,C 類條款優先於 A/B 類——因為 C 類是針對該機種的危害量身訂做的。==例如沖床的 C 類標準對雙手操作、光柵位置有具體規定,做沖床就照它,而不是自己拿 B 類重新推導一遍。

⚠️ 注意:C 類「沒講到的部分」仍回歸 A/B 類。C 類優先不是「有 C 類就不用管其他標準」,而是「重疊時聽 C 類的」。你的機種沒有 C 類標準?那就直接用 A + B 類自行完成風險評估——這正是 12100 存在的意義。

## 2.3 台灣的對應:CNS 與職安法規

| **國際標準** | **台灣對應** | **性質** |
|---|---|---|
| ISO 12100 | CNS 機械安全一般設計原則 | 自願性國家標準 |
| 各 C 類標準 | 職安法「機械設備器具安全標準」(沖剪機械、堆高機、研磨機等章節) | **法規強制**,違反可罰 |
| — | 職安法「機械設備器具安全資訊申報」制度 | 指定機械上市前須申報符合安全標準 |

※ 備註:實務上台灣機械廠的常見組合是「國內交機看職安法規+CNS,出口機看 ISO/IEC/EN」。兩套的骨架都是 12100 的風險評估,做一套完整評估文件,兩邊都能交代。

# 3. 風險評估流程

## 3.1 全流程一張圖

12100 的主流程用文字畫出來就是:

1. **界定機械限制**(這台機器是什麼、給誰用、用在哪)
2. **危害識別**(有哪些會傷人的東西)
3. **風險估計**(每個危害有多危險)
4. **風險評價**(這樣的風險能不能接受)
5. 不能接受 → **風險降低三步法**(第 4 章)→ 回到步驟 2 重新評估
6. 能接受 → 把殘餘風險寫進使用資訊,結案存檔

==風險評估(步驟 1~4)是「診斷」,風險降低(三步法)是「治療」,兩者交替迭代直到風險可接受——這個迴圈就是整本 12100。==

## 3.2 第一步:界定機械限制

先把「評估對象」的邊界畫清楚,不然危害會找不完也找不對。四種限制:

| **限制類型** | **白話問題** | **設備例(輸送機)** |
|---|---|---|
| 使用限制 | 給誰用?做什麼用?會不會被誤用? | 操作員上下料、師傅排除卡料——「伸手進去撥」就是可預見的誤用 |
| 空間限制 | 機器多大?人會站哪?維修空間夠嗎? | 操作側走道、皮帶下方清潔空間 |
| 時間限制 | 零件壽命?保養週期? | 皮帶壽命、軸承更換週期 |
| 其他限制 | 環境(溫濕度、粉塵)、材料特性 | 粉塵環境影響光電感測器可靠度 |

⚠️ 「合理可預見的誤用」必須納入評估——師傅嫌停機麻煩、跨過護欄去清卡料,這不是「他自己違規不關我的事」,而是設計時就該預見的使用方式。==設計者要防的不只是正確使用,還有可預見的偷懶用法。==

## 3.3 第二步:危害識別

拿著清單逐項掃過整台機器、整個生命週期(安裝、運轉、調機、保養、拆除)。常見危害類型:

| **危害類型** | **白話說明** | **設備例** |
|---|---|---|
| 機械性危害 | 夾、捲、剪、切、刺、撞、壓 | 輸送機頭尾輪夾點、齒輪捲入、沖床模區 |
| 電氣危害 | 感電、電弧 | 盤內帶電部、破損電纜(詳見第五部手冊) |
| 熱危害 | 燙傷、高溫輻射 | 射出機料管、熱處理爐、剛停機的馬達外殼 |
| 噪音危害 | 聽力損失、聽不到警報 | 沖床、空壓機、料件碰撞 |
| 振動危害 | 手臂振動症候群 | 手持研磨機、振動送料機 |
| 物質危害 | 吸入、接觸有害物 | 切削油霧、焊接燻煙、清洗溶劑 |
| 人因危害 | 姿勢不良、施力過大、精神負荷 | 重物搬運上料、長時間彎腰取件 |
| 滑倒墜落 | 滑、絆、摔 | 油污地面、跨越輸送帶、平台無護欄 |

💡 識別技巧:對著機器問三句話——「哪裡會動?」(機械性)、「哪裡有能量?」(電、熱、壓力、位能)、「人會在哪裡做什麼?」(操作、保養、排除異常)。三句話交叉掃過,漏網之魚會少很多。

🚫 常見踩坑:只評「正常運轉」。多數事故發生在**排除卡料、調機、清潔保養**——機器半開、防護被拆、人最靠近危險點的時刻。生命週期每個階段都要掃。

## 3.4 第三步:風險估計

每個危害的風險大小,由兩大因素構成:**傷害的嚴重度 × 傷害發生的可能性**。可能性再拆成三個子因素:

| **要素** | **白話問題** | **粗分級距例** |
|---|---|---|
| 嚴重度(S) | 最壞會傷多重? | 輕傷(擦挫傷,可復原)/重傷(斷指、失能、死亡) |
| 暴露頻率(F) | 人多常靠近危險區? | 偶爾(每班少於一次)/頻繁(每班多次、長時間) |
| 可避免性(P) | 危險來了躲得掉嗎? | 可避免(速度慢、看得到)/難避免(高速、突發、空間窄) |

估出來的組合決定風險高低,也直接餵給 ISO 13849-1 的風險圖去選安全迴路的 PL 等級——這就是 A 類與 B 類的銜接點。

※ 備註:12100 本身不強制用哪一種計分法。風險圖、風險矩陣、數值計分都可以,重點是**同一份評估用同一把尺**,而且判斷理由寫得出來。

## 3.5 第四步:風險評價

拿估計結果問一句:「這樣可以接受了嗎?」判斷依據:

- C 類標準有規定 → 照 C 類做到就視為可接受(這是 C 類最好用的地方);
- 沒有 C 類 → 比照類似機械的公認水準、業界狀態與法規要求;
- 不可接受 → 進入風險降低三步法,降完**回到步驟 2 重新評估**。

# 4. 風險降低三步法(全書最重要)

==風險降低有法定順序:①本質安全設計 → ②安全防護與補充保護 → ③使用資訊。必須先窮盡上一步,才能靠下一步——順序不可顛倒。==

為什麼順序這麼重要?因為三步的可靠度天差地遠:本質安全「危害根本不存在」,防護裝置「危害還在,靠設備擋」,使用資訊「危害還在,靠人自己小心」。人是最不可靠的一環,所以把安全押在人身上是最後不得已的手段。

!!絕不能用第三步取代前兩步——貼「小心夾手」貼紙,永遠不能代替裝護罩。事故調查時,「明明裝得了護罩卻只貼標籤」是設計者責任最重的一種。!!

## 4.1 第一步:本質安全設計

在設計源頭讓危害「消失」或「小到傷不了人」,不靠任何附加裝置:

| **手法** | **白話說明** | **例子** |
|---|---|---|
| 消除危害 | 改設計讓危險點不存在 | 加大輥輪間隙讓夾點夾不到手指;去毛邊、導圓角 |
| 降低能量 | 能量小到不足以造成傷害 | 調機模式限速(慢到躲得開);夾持力限制;降低電壓 |
| 改變佈置 | 危險點移到人碰不到的地方 | 傳動機構收進機體內;加料口墊高到伸手不及 |
| 自動化取代 | 人不用進危險區 | 自動上下料取代人工伸手取件 |
| 可靠的工程原則 | 零件不會先壞出危險 | 依規範選安全係數、防鬆脫設計 |

💡 判斷口訣:問「這個危害能不能**設計掉**?」能設計掉的就別用護罩擋。護罩會被拆、會被打開,設計掉的危害永遠回不來——==最好的防護是讓危害根本不存在。==

## 4.2 第二步:安全防護與補充保護

本質安全做不掉的殘餘危害,用**防護裝置**把人與危害隔開:

- **固定式護罩**:鎖死的罩子,要用工具才拆得掉。最簡單、最可靠,不常進出的危險區首選。
- **活動式護罩+聯鎖**:會開的門配安全開關(-BG)——==門開機停,門沒關機不能跑==(選型細節歸 ISO 14119)。
- **安全光柵/安全地毯**:手或人一進偵測區就停機,適合需要頻繁進出、裝門會擋作業的地方。
- **雙手操作裝置**:兩顆按鈕同時按機器才動作——確保雙手都不在模區(沖床常見)。

**補充保護措施**(complementary protective measures):防護之外的「後備手段」,最典型就是**急停**。

!!急停是「補充保護」,不是防護裝置!它是出事之後讓事態不要更糟的最後手段,不能當作把人與危害隔開的方法——「反正有急停」永遠不是省略護罩的理由。!!

![急停按鈕](images/qet-estop.svg) ![蘑菇頭操作件](images/mark-mushroom.svg)

⚠️ 順帶一提:急停的電氣行為(紅蘑菇黃底、常閉接點、拍下保持)在第五部手冊 5.3 節;本章只管它在風險降低架構裡的「定位」。

## 4.3 第三步:使用資訊

前兩步做完仍除不掉的**殘餘風險**,用資訊告知使用者:

| **手段** | **內容** |
|---|---|
| 機上標示 | 警告標誌、燈號、聲響警報——貼在危害旁邊、看得到的位置 |
| 使用說明書 | 殘餘風險清單、正確操作程序、保養程序、個人防護具(PPE)要求 |
| 訓練要求 | 說明書中載明操作者需具備的訓練與資格 |

==使用資訊是「三步法的收尾」,不是「風險降低的捷徑」——它處理的只能是前兩步窮盡後的殘餘風險。==

# 5. 常見防護裝置對照表

| **裝置** | **原理(白話)** | **適用場合** | **注意事項** |
|---|---|---|---|
| 固定式護罩 | 鎖死的罩子,工具才能拆 | 不常進出的傳動區、皮帶輪 | 拆下後螺絲要留在護罩上(防拆了不裝回) |
| 活動式護罩+聯鎖(-BG) | 門開→安全開關斷→機停 | 每天要開的加料門、檢修門 | 開關要防「拿磁鐵/備用鑰匙騙過」(ISO 14119) |
| 帶鎖聯鎖護罩 | 機器沒停完,門鎖著打不開 | 慣性大、停得慢的機器(離心機、大飛輪) | 鎖的失效模式要選對(斷電鎖住或斷電解鎖) |
| 安全光柵 | 光幕被遮斷→停機 | 頻繁上下料、裝門礙事的開口 | 安裝距離要依停機時間算(手比光快就白裝) |
| 安全地毯 | 人踩上→停機 | 機器人工作區、大範圍進入偵測 | 只防「站進去」,不防「伸手進去」 |
| 雙手操作 | 兩鈕同按才動作 | 沖床、裁斷機的單人操作 | 只保護操作者本人,旁邊的人要另外防 |
| 急停 | 拍下→立即停機且保持 | 全機必備的補充保護 | 不是防護裝置,不能取代以上任何一項 |

🚫 選錯型的經典案例:頻繁進出的門裝固定式護罩→師傅嫌煩把螺絲拆了不裝回→等於沒有護罩。**防護裝置要配合作業節奏選型,好用的防護才會被留著用。**

# 6. 迭代與殘餘風險

## 6.1 降完要重評:迭代到可接受為止

每加一道風險降低措施,就要回到流程重新評估:

1. 原危害的風險降夠了嗎?
2. ==措施本身有沒有帶來新危害?==(加了護罩多了夾手邊角?加了光柵停機太突然造成料件飛出?)
3. 有沒有讓機器難用到「大家都想繞過防護」?(難用的防護=沒有防護)

三個問題都過關,才算這一輪迭代完成。全部危害都降到可接受,評估才收斂。

## 6.2 殘餘風險寫進說明書

降不掉的殘餘風險不是「假裝沒看到」,而是**明文寫進使用說明書**:哪裡還有什麼危險、操作時要怎麼防、要戴什麼 PPE、誰才能操作。==殘餘風險的告知是設計者的交付義務——說明書裡的殘餘風險章節,就是風險評估的最終輸出之一。==

# 7. 實務情境範例

## 7.1 情境一:輸送機夾點的三步法處理

**背景:**皮帶輸送機尾輪處,皮帶與輥輪的咬合點是典型夾點(捲入危害)。操作員每班會在附近整理料件。

**風險估計:**嚴重度高(手捲入→斷指以上)、暴露頻繁(每班多次靠近)、難避免(捲入速度快)→ 風險不可接受,進三步法:

| **步驟** | **檢討** | **決定** |
|---|---|---|
| ① 本質安全 | 能不能消除夾點?→ 尾輪結構上無法取消;但可將尾輪內縮進機架,縮小暴露範圍 | 採用:內縮設計 |
| ② 安全防護 | 剩餘的咬合區加固定式護罩(此處不需頻繁進出);全線拉緊急拉繩開關作補充保護 | 採用:固定護罩+拉繩急停 |
| ③ 使用資訊 | 護罩上貼捲入警告標誌;說明書載明「清潔皮帶必須停機上鎖(LOTO)」 | 採用:標示+程序 |

**重新評估:**護罩開孔尺寸對照 ISO 13857 安全距離表,確認手指伸不進咬合點;護罩本身無銳邊。殘餘風險(維修時拆罩作業)寫入說明書,由 LOTO 程序管制。結案。

💡 注意順序:先想「設計掉」(內縮),再想「擋起來」(護罩),最後才是「告訴他」(標示+程序)。三步都用上,而不是跳到最後一步貼張貼紙了事。

## 7.2 情境二:改機加裝置後的重新評估

**背景:**客戶要求在既有包裝機出料口加裝一台貼標機。改機師傅把貼標機鎖上、電拉好,測試 OK 準備交機。

**問題:**原機的風險評估是「沒有貼標機」時做的。加裝後:

- 出料口原本的開口距離夠遠(依 13857 手伸不到危險點),加了貼標機後**多了新的夾點**,而且位置更靠近操作員;
- 貼標機與包裝機的急停**各自獨立**——拍包裝機急停,貼標機還在動。

**正確做法:**

1. 對「改動影響範圍」重新走一遍風險評估:新增危害(貼標機夾點)、被改變的既有條件(開口距離、動線);
2. 新夾點依三步法處理(調整佈置→加護罩→標示);
3. 急停整合:==兩機急停互鎖成一個急停區,拍任何一顆全區都停==(急停範圍劃分見第五部手冊);
4. 更新風險評估文件與使用說明書,一併交付客戶。

!!改機必須重新風險評估——「原機有 CE、改完當然還是安全的」是危險的錯覺。誰改機,誰就承擔改動部分的設計者責任。!!

# 8. 常見問答(FAQ)

**Q1:急停到底算不算防護裝置?**

不算。急停是**補充保護措施**——它不隔開人與危害,只是出事時的最後手段。防護裝置(護罩、光柵)的作用是「讓事故不發生」,急停是「事故發生時降低傷害」。所以風險評估表上,不能拿「有急停」當作某個危害的防護對策;護罩該裝還是要裝。

**Q2:貼警告貼紙就好了嗎?**

不行。貼紙屬於三步法的第三步(使用資訊),只能處理前兩步窮盡後的殘餘風險。裝得了護罩的地方只貼貼紙,在事故調查與產品責任上站不住腳。反過來說,前兩步做完了,貼紙(加上說明書)是必要的收尾——該貼的還是要貼,只是它永遠不是主角。

**Q3:風險評估誰做?要什麼資格?**

由**設計者主導**,因為只有設計端有能力執行第一步(本質安全設計)。實務上建議小組進行:設計工程師+電控工程師+熟悉現場的人(組裝師傅、客戶端操作主管)——設計者知道機器怎麼動,現場的人知道人實際上怎麼用(包括怎麼偷懶)。12100 沒有規定證照,但評估者要熟悉這套方法與相關 B/C 類標準。

**Q4:風險評估文件要留什麼?留多久?**

至少留:機械限制界定、危害清單、每項危害的風險估計與評價、採用的降低措施與依據標準、殘餘風險與對應的使用資訊、評估人員與日期。這份文件是 CE 技術文件的核心,也是事故時證明「設計者已盡責」的第一憑據——==風險評估沒有文件,等於沒做。==保存期限跟著機器壽命走,至少到停產後法規要求年限。

**Q5:小廠做一台簡單的機器,也要搞這麼大一套嗎?**

流程一樣,深度可以對應機器複雜度。一台小輸送機的風險評估可能就是兩頁表格:限制界定五行、危害清單十項、每項一行對策。重點是**有系統地掃過、有文件**,而不是文件厚度。越簡單的機器越快做完,更沒有不做的理由。

**Q6:已經照 C 類標準做了,還要做風險評估嗎?**

要,但輕鬆很多。C 類涵蓋的危害,照 C 類做到就視為可接受,評估表直接引用條款即可;但你的機器若有 C 類沒涵蓋的部分(特殊選配、非標設計、與其他設備的介面),那些部分仍要自行走完評估流程。

# 9. 常見踩坑總整理

| **# ** | **錯誤做法** | **會發生什麼** | **正確做法** |
|---|---|---|---|
| 1 | 跳過本質安全,直接裝護罩 | 護罩被拆、被繞過,危害復活 | 先問「能不能設計掉」,窮盡第一步再進第二步 |
| 2 | 用警告貼紙取代護罩 | 事故照發生,設計者責任最重 | 貼紙只收尾殘餘風險,擋危害靠前兩步 |
| 3 | 把急停當防護對策寫進評估表 | 危害與人之間其實沒有任何隔離 | 急停列為補充保護;隔離靠護罩/光柵 |
| 4 | 只評估正常運轉 | 排卡料、調機、保養時出事 | 生命週期各階段(含異常排除)逐一掃過 |
| 5 | 「誤用是使用者的錯」不納入評估 | 可預見的偷懶用法沒人防,事故後才知道 | 合理可預見的誤用一律納入限制界定 |
| 6 | 改機不重新評估 | 新夾點、急停不連動,原評估失效 | 改動範圍重新走流程,文件同步更新 |
| 7 | 頻繁進出的門裝固定護罩 | 螺絲被拆掉不裝回 | 依作業節奏選型:常開的門用聯鎖護罩 |
| 8 | 光柵裝太近危險點 | 手比停機快,遮斷了照樣夾到 | 依停止時間計算安裝距離再定位 |
| 9 | 加了防護沒有重新評估 | 防護本身帶來新危害(夾點、銳邊、視線遮蔽) | 每輪措施後迭代重評,確認無新危害 |
| 10 | 殘餘風險不寫進說明書 | 使用者不知道剩什麼危險,告知義務未履行 | 殘餘風險明文列入說明書與機上標示 |
| 11 | 風險評估口頭做、不留文件 | 驗收、認證、事故調查全部拿不出憑據 | 用表單記錄全程,人員日期齊備 |
| 12 | 有 C 類標準卻自己土法推導 | 做法與公認水準不符,驗收被打槍 | 先查 C 類,有規定照做並引用條款 |

# 附錄 A:風險評估表單欄位範例

一張堪用的風險評估表,每一列(一個危害一列)建議至少包含:

| **欄位** | **填寫內容** |
|---|---|
| 編號 | 危害流水號(供追蹤與引用) |
| 生命週期階段 | 運轉/調機/保養/清潔/安裝拆除 |
| 位置與危害描述 | 哪裡、什麼類型危害、傷害情境(如:尾輪夾點,手捲入) |
| 風險估計(措施前) | S/F/P 分級與風險等級 |
| 降低措施 | 依三步法標明:①設計/②防護/③資訊,引用的標準條款 |
| 風險估計(措施後) | 同一把尺重新估 |
| 評價結果 | 可接受/不可接受(不可接受→下一輪迭代) |
| 殘餘風險與去向 | 寫入說明書第幾節、機上標示位置 |
| 評估人/日期 | 小組成員與版次——改機時就從這裡開新版 |

※ 備註:表頭處另留整機資訊:機型、機號、機械限制界定摘要、參用的 C 類標準清單、評估方法(用哪種風險圖/矩陣)。
