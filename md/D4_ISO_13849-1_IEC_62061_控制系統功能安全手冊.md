# 1. 前言

## 1.1 本冊的定位:60204-1 教你「怎麼接」,13849 教你「夠不夠可靠」

第五部手冊(IEC 60204-1)教了急停的「長相與行為」:紅蘑菇黃底、**常閉**接點、直接開路動作、復位不得自行再起動。照著做,你的急停「接法」合規了——但還有一個問題沒回答:

**這條急停迴路,壞掉的機率夠低嗎?**

繼電器接點會熔黏、線會斷、接觸器會卡住。如果急停鏈裡任何一個元件壞掉的那天,剛好有人拍下急停——機器不停,那條迴路畫得再標準也沒用。ISO 13849-1 管的就是這件事:==把安全迴路的「可靠度」量化成 PL 等級(a~e),像一張可靠度成績單——迴路的成績(PL)必須大於等於風險要求的分數(PLr),才算合格。==

打個比方:60204-1 像建築法規教你「樑柱怎麼配筋」;13849 像耐震設計——先查這塊地要求耐幾級震(PLr),再算你這棟房子實際耐幾級(PL),**達成 ≥ 需求**才能拿使用執照。接法對、可靠度不夠,一樣不能交機。

💡 什麼時候會用到本冊?只要機器上有「靠控制系統實現的安全功能」——急停、安全門、光柵、雙手操作——CE 認證與多數外商客戶規範都會要求你交出 PL 計算與驗證證據。60204-1 的圖面合規+13849 的可靠度合規,兩張證明都要有。

## 1.2 13849(PL)與 62061(SIL):同一件事的兩套算法

兩份標準管的是同一件事(安全相關控制系統的可靠度),只是出身不同、量尺不同:

| **面向** | **ISO 13849-1(PL)** | **IEC 62061(SIL)** |
|---|---|---|
| 出身 | 機械界(ISO 12100 家族) | 電氣界(IEC 61508 功能安全家族) |
| 量尺 | Performance Level:PL a~e | Safety Integrity Level:SIL 1~3 |
| 涵蓋技術 | 電氣、液壓、氣壓、機械都能算 | 以電氣/電子/可程式系統為主 |
| 業界主流 | **一般產業機械幾乎都用它** | 大型系統、製程整合案較常見 |
| 常用工具 | SISTEMA(IFA 免費軟體) | 廠商計算工具/顧問 |

兩把尺可以互換讀數,對照如下(PFHd=每小時危險失效機率,數字愈小愈可靠):

| **PL** | **PFHd(每小時)** | **對應 SIL** |
|---|---|---|
| a | 10⁻⁵ ~ 10⁻⁴ | 無對應 |
| b | 3×10⁻⁶ ~ 10⁻⁵ | SIL 1 |
| c | 10⁻⁶ ~ 3×10⁻⁶ | SIL 1 |
| d | 10⁻⁷ ~ 10⁻⁶ | SIL 2 |
| e | 10⁻⁸ ~ 10⁻⁷ | SIL 3 |

※ 實務建議:做機械的,選 **ISO 13849-1** 一套做到底即可;客戶規範寫 SIL 2 時,用上表換算成 PL d 來設計與舉證,絕大多數客戶都接受(合約先確認)。==兩套標準擇一適用即可,不必兩套都算——同一條迴路算兩次不會變得更安全。==

## 1.3 適用範圍與版本

- **管什麼:**安全相關控制系統的「安全相關部分」(SRP/CS)——從感測器(急停鈕、門開關、光柵)、邏輯(安全繼電器、安全 PLC)到最終切斷元件(接觸器、閥、STO)的整條鏈。
- **不管什麼:**風險評估本身(那是 ISO 12100)、電氣接法細節(那是 60204-1)、急停的人因外觀(那是 ISO 13850)。
- **版本:**ISO 13849-1:2023(第 4 版)、IEC 62061:2021(第 2 版)。2023 版把驗證(原 13849-2 的一部分)整併進來,對使用者的日常影響不大,本冊白話講法兩版通用。

# 2. 名詞白話化:安全功能、PL、PLr

**安全功能(Safety Function):**「偵測到某個危險條件 → 機器做出某個安全反應」的一條完整因果,就是一個安全功能。重點是「一條算一條」:

| **安全功能** | **偵測** | **反應** |
|---|---|---|
| 急停 | 有人拍下急停鈕 | 全機進入安全狀態(類別 0/1 停止) |
| 門開停機 | 安全門被打開 | 門內危險運動停止 |
| 光柵停機 | 光幕被遮斷 | 該區運動停止 |
| 雙手操作 | 任一手離開按鈕 | 沖壓行程停止 |

==一台機器有幾個安全功能,就要做幾次「查 PLr → 設計 → 算 PL → 實測」的循環——急停是急停、安全門是安全門,各自評、各自算、各自測。==

**PL(Performance Level,性能等級):**安全功能「實際做到」的可靠度等級,a 最低、e 最高。它是算出來的:由迴路架構(Category)、元件耐用度(MTTFd)、診斷能力(DC)、共因故障(CCF)四個因素共同決定(第 5 章)。

**PLr(required PL,需求性能等級):**風險評估「要求要做到」的等級,從風險圖查出來(第 3 章)。r 就是 required。

⚠️ 一句話記住兩者關係:==PLr 是「考題難度」(查出來的),PL 是「你的成績」(算出來的);**PL ≥ PLr** 才及格。==成績單漂亮但考錯科目也不行——每個安全功能對自己的 PLr 負責。

**整條鏈原則:**一個安全功能=感測器+邏輯+致動器的**整條鏈**。買了 PL e 的安全繼電器,只代表「邏輯」那一段很強;如果最後只用一顆普通接觸器切斷,整條鏈的 PL 由最弱的一段決定。==安全迴路像鎖鏈,等級看最弱的那一環——感測、邏輯、致動三段都要算進去。==

# 3. PLr 風險圖:這條迴路要做到多可靠

PLr 用三個問題查表決定,問的都是「如果這個安全功能失效、危險真的發生」的情境:

| **參數** | **問題** | **選項** |
|---|---|---|
| S 嚴重度 | 傷得多重? | S1 輕傷(可復原:瘀傷、輕割傷)/S2 重傷(不可復原:斷指、死亡) |
| F 暴露頻率 | 人多常暴露在危險區? | F1 少(偶爾進去、時間短)/F2 常(每班多次或停留長,經驗值:每小時超過一次選 F2) |
| P 可避免性 | 危險來了躲得掉嗎? | P1 有機會避開(動作慢、看得到、空間夠)/P2 幾乎躲不掉(速度快、看不到) |

三個問題答完,直接查表:

| **S** | **F** | **P** | **PLr** |
|---|---|---|---|
| S1 | F1 | P1 | a |
| S1 | F1 | P2 | b |
| S1 | F2 | P1 | b |
| S1 | F2 | P2 | c |
| S2 | F1 | P1 | c |
| S2 | F1 | P2 | d |
| S2 | F2 | P1 | d |
| S2 | F2 | P2 | e |

**實例走一遍|加工機的安全門聯鎖:**門內是旋轉主軸。傷害:捲入=斷手等級 → **S2**;操作員每班開門上下料幾十次 → **F2**;主軸減速需要幾秒,開門瞬間伸手大概率碰到 → 保守取 **P1**(若門一開手就在刀尖旁,取 P2)。查表:S2F2P1 → ==**PLr = d**。這就是為什麼業界常說「安全門做 PL d」——S2F2P1 是產業機械最常見的組合,PL d 因此成為最常見的設計目標。==

**再走一個對照組|沖床的光柵停機:**沖頭下行=斷手 S2;每個行程都伸手取放料 F2;沖程零點幾秒、完全躲不掉 P2 → S2F2P2 → **PLr = e**。同樣是「擋住手」,加工機安全門查出 d、沖床光柵查出 e——差在 F 與 P,不差在設備貴不貴。這也是為什麼沖壓業的安全料件等級普遍高一級。

💡 判斷原則:選項猶豫時往嚴的選(S1/S2 拿不準就當 S2)。PLr 差一級,後面架構差很多(單通道 vs 雙通道),但「賭輕傷」賭輸的是別人的手。

※ 風險圖屬於風險評估(ISO 12100)的一環,由誰評?理想是設計、製造、使用端一起評;實務上機械廠設計者先評、留下紀錄,客戶驗收時對答案。

# 4. 架構類別 Category B/1/2/3/4

## 4.1 五個類別白話拆解

Category 回答的是「迴路長什麼樣」:幾條通道?有沒有人在監督?壞一個元件會怎樣?

| **Category** | **白話結構** | **壞一個元件會怎樣** | **可達 PL(上限)** |
|---|---|---|---|
| B | 單通道,基本款(元件符合基本要求即可) | 安全功能直接失效 | b |
| 1 | 單通道,但用「久經考驗」的可靠元件 | 一樣直接失效,只是機率較低 | c |
| 2 | 單通道+定期自我測試(監控) | 失效有機會被測試抓到 | d |
| 3 | **雙通道**+交叉監控 | ==**單一故障不失效**——壞一條,另一條照樣停機== | d |
| 4 | 雙通道+高診斷,連故障累積都要撐住 | 單一故障不失效,且故障會被即時偵測 | e |

雙通道像雙保險:登山主繩之外再掛一條確保繩——主繩斷了人不會掉,而且教練(監控電路)每次都檢查兩條繩,發現其中一條磨損就禁止出發。這就是 Cat 3 的精神:**容忍一個故障+發現大部分故障**。

💡 快速對應(業界經驗值,詳算仍看第 5 章):PLr b/c → 單通道(Cat 1)常常夠;PLr d → 雙通道(Cat 3)是標準答案;PLr e → 基本上就是 Cat 4。==PL e 基本上=Cat 4:雙通道+高診斷覆蓋率,單靠堆好元件堆不出 e。==

**Cat 3 迴路長怎樣(最常抄的一款):**

![急停按鈕](images/qet-estop.svg) ![常閉接點](images/qet-contact-nc.svg) ![線圈](images/qet-coil.svg) ![三相主接觸器](images/qet-contactor-main-3p.svg)

急停鈕出**兩個獨立常閉接點**(通道 1、通道 2)→ 兩路各自接進安全繼電器的兩個輸入 → 安全繼電器安全輸出驅動**兩顆接觸器**,主迴路上兩顆串聯 → 兩顆接觸器的強制導向常閉接點串回安全繼電器的回授端子。感測雙路、切斷雙重、外加監督——這一條迴路就把 Cat 3 的三個要素(冗餘、監控、抗共因)都做齊了,細節見 6.1。

## 4.2 安全繼電器在做什麼

安全繼電器(safety relay,現場常直接喊廠牌如 PNOZ)外表像一顆窄軌繼電器模組,裡面做四件一般繼電器做不到的事:

| **功能** | **在防什麼** | **白話** |
|---|---|---|
| 雙通道輸入 | 一條斷線/一個接點失效 | 兩條都閉合才允許運轉;不一致就停機並鎖住 |
| 交叉短路偵測 | 兩條通道被短接在一起(線被壓破、有人跳線) | 兩通道用不同測試脈波,被短接立刻辨識出來 |
| 強制導向接點回授(EDM) | 下游接觸器熔黏 | 復位前檢查接觸器「真的放開了」,黏住就拒絕復位(6.1 詳講) |
| 復位監控 | 復位鈕被卡死/短接、上電自動復位 | 監測復位鈕「按下再放開」的邊緣,壓著不放不算數 |

⚠️ 「強制導向接點」(force-guided / mirror contact)白話:繼電器/接觸器內部機構保證**常開與常閉接點不可能同時閉合**——主接點熔黏時,常閉接點被機構「撐住」不會閉合,外部因此讀得到「它還黏著」的證據。一般繼電器沒有這個機構,常閉接點回彈了、主接點卻還黏著,監控電路會被騙。

# 5. 影響 PL 的四要素:Category、MTTFd、DC、CCF

PL 不是只看架構,四個因素一起決定。工程師要會「看懂與選料」,詳細計算交給 SISTEMA 軟體+元件廠 datasheet:

| **要素** | **白話一句** | **現場例** | **分級** |
|---|---|---|---|
| Category | 迴路長什麼樣(第 4 章) | 單通道還是雙通道、有沒有回授 | B/1/2/3/4 |
| MTTFd | 元件多耐用(平均多少年才發生一次危險失效) | 型錄上的 MTTFd 或 B10d(機電元件:多少次動作壞一次,再除以你的操作頻率) | 低 3~10 年/中 10~30 年/高 30~100 年 |
| DC 診斷覆蓋率 | 故障發生時,被監控電路「抓到」的比例 | 有 EDM 回授=接觸器熔黏抓得到;沒回授=抓不到 | 無 <60%/低 60~90%/中 90~99%/高 ≥99% |
| CCF 共因故障 | 一個原因同時打死兩條通道的機率 | 兩通道走同一條電纜被同一把刀壓斷;同批次元件同時老化 | 檢查表計分,≥65 分及格(Cat 2 以上必做) |

四要素的關係一句話:==Category 決定天花板,MTTFd 決定你在天花板下站多高,DC 幫你把沒把握的部分「用監控補回來」,CCF 是雙通道的資格審查——雙通道若會被一刀齊斷,等於只有一條。==

💡 實務流程:選好 Category → 從元件 datasheet 抄 MTTFd/B10d/PFHd → 在 SISTEMA 建鏈 → 軟體吐出 PL。SISTEMA 是德國 IFA 的免費軟體,各大廠(Pilz、SICK、Schneider…)都提供可直接匯入的元件庫;新手不必手算任何公式,但要看得懂自己輸入了什麼。

🚫 選型只比 Category 是常見錯誤:同樣 Cat 3,用了 MTTFd「低」的雜牌接觸器,算出來可能只有 PL c;反之 Cat 2 配高 MTTFd+中 DC 也能到 PL d。**等級是算出來的,不是宣稱出來的。**

# 6. 典型安全迴路範例

## 6.1 範例一:急停鏈(雙常閉 → 安全繼電器 → 雙接觸器)

最常見的 Cat 3/PL d 急停迴路,逐段拆解:

![急停按鈕](images/qet-estop.svg)

- **感測段:**急停鈕使用**兩個獨立常閉接點**(-SF9:通道 CH1、CH2)。為什麼兩個?一個接點氧化、斷線或被震開,另一路還能通知安全繼電器。兩路配線分開走(防共因)。

- **邏輯段:**安全繼電器(-KF5)接收兩路輸入、做交叉短路偵測;任一路開路或兩路不一致 → 安全輸出立即斷開並鎖住,須手動復位。

![三相主接觸器](images/qet-contactor-main-3p.svg)

- **致動段:**安全輸出驅動兩顆接觸器(-QA2、-QA3),**主迴路上兩顆串聯**。
  - **為什麼要兩顆接觸器?**接觸器最可怕的失效模式是主接點熔黏——線圈斷電了,接點還黏著,馬達照轉。一顆熔黏=急停失效;==兩顆串聯,一顆熔黏另一顆照樣切斷——這就是「單一故障不失效」落到主迴路上的具體長相。==

- **回授段(EDM):**兩顆接觸器的強制導向**常閉**輔助接點串聯,接回安全繼電器的回授/復位迴路。
  - **回授迴路在防什麼?**防「熔黏的那顆沒人發現」。復位時安全繼電器檢查:兩顆常閉回授都閉合=兩顆都確實放開了,才允許復位;若 -QA2 熔黏,它的常閉回授開路 → ==回授不通=拒絕復位——機器用「起不來」逼你去修那顆黏住的接觸器,而不是帶著半條急停繼續生產。==

!!回授迴路(EDM)嚴禁短接。跳線短接後,接觸器熔黏將無人知道、無物阻止——下一次拍急停,機器不停。查機時看到回授端子上亮晶晶的短路片,就是在看一條被拆掉保險的急停。!!

※ 變頻器機台的變化款:致動段可改用變頻器 STO 端子(見第五部 5.3),STO 雙通道輸入直接由安全繼電器驅動;高風險場合常 STO+接觸器並用,一道電子、一道機械。

![變頻器](images/qet-vfd.svg)

## 6.2 範例二:安全門聯鎖

![極限開關](images/qet-limit-switch.svg)

- **感測段:**安全門開關兩通道。傳統做法:一顆「直接開路動作」的舌片式安全開關(門一開,凸輪**強制撐開**常閉接點,不靠彈簧)+第二通道;現代主流:RFID 編碼式安全開關,天生雙通道(OSSD 輸出)、防作弊(拿一片鐵片貼上去騙不過它)。
- **邏輯段+致動段:**與急停鏈相同——安全繼電器(或安全 PLC 輸入)→ 雙接觸器+EDM。
- **設計重點:**
  - !!安全門不得使用一般極限開關的彈簧回彈接點——彈簧疲勞或接點熔黏時,門開了訊號還在「閉合」,迴路以為門還關著。安全開關必須是直接開路動作(符號上有 ⊖ 標記)或編碼式。!!
  - 停得下來才准開門:主軸慣量大時要加**上鎖型**(guard locking)門鎖——門鎖到危險運動確實停止才釋放,別讓「門開了、主軸還在轉」發生。
  - 防規避:開關裝在人搆不到/工具才拆得掉的位置;編碼式開關天然防規避,是它貴得有道理的地方。

## 6.3 範例三:安全光柵

![光電感測](images/qet-photo-no.svg)

- **感測段:**Type 4 安全光柵(對應 PL e 能力)自帶雙通道 OSSD 電晶體輸出與連續自我測試——光柵每秒自測數百次,自己壞了自己把輸出拉掉。
- **邏輯段+致動段:**OSSD 兩路進安全繼電器/安全 PLC → 雙接觸器+EDM,同前。
- **設計重點:**
  - **安全距離:**光柵要裝在「手伸進去到危險點之前,機器來得及停下」的距離之外,概念公式 S=K×T+C(K:手的逼近速度,常取 2 000 mm/s;T:整條鏈的總停止時間;C:依解析度的補正)。==光柵擋不擋得住,不看光柵多貴,看它裝得夠不夠遠——總停止時間實測出來,距離才算得出來。==
  - **防繞過:**上下左右都不能有「不遮光就伸得進去」的縫隙;人若能站進光柵與危險點之間,還要加水平光柵或重啟聯鎖(人在裡面時,外面不能復位)。
  - **重啟聯鎖:**遮斷後不得自動再起動,須在看得見危險區的位置手動復位(呼應第五部「復位≠起動」)。

# 7. 驗證:計算書+實測,缺一不可

PL 的證據分兩張,對應「算得對」與「做得對」:

| **證據** | **內容** | **在證明什麼** |
|---|---|---|
| 計算書(SISTEMA 報告) | 每個安全功能:PLr 判定依據(S/F/P)、迴路架構、元件清單與 MTTFd/DC/CCF、算得的 PL | 設計上 PL ≥ PLr |
| 功能實測(驗證測試) | 每個安全功能逐一觸發:拍每一顆急停、開每一道門、遮光柵每一區,確認反應與復位行為正確 | 實機行為與設計一致 |

實測的最低套路(併入第五部第 8 章的出廠功能測試一起做):

- 逐一觸發:每一顆急停、每一道門、每一支光柵——不是抽測一顆代表全部。
- 測「壞掉的樣子」:拔掉一條通道的線再觸發,確認安全繼電器偵測到不一致並鎖住;短接測試交叉短路偵測是否動作。
- 測回授:手動保持一顆接觸器(模擬熔黏),確認拒絕復位。
- 測復位行為:復位後機器必須保持停止,等起動鈕才動。
- 記錄:結果寫入測試報告(&QC001)隨機交付,與計算書一起歸檔。

!!安全迴路只要改動(換元件、改接線、改程式),計算書與受影響的功能實測都要重做——換了一顆「規格一樣」的接觸器,MTTFd 已經不是原來的數字,測試紀錄也已經不是這台機器的證據。!!

# 8. 實務情境範例

## 8.1 情境一:輸送機急停迴路的 PL 走查

沿用系列範例的單站輸送機,把本冊流程完整走一遍:

| **步驟** | **本案內容** | **依據章** |
|---|---|---|
| 定義安全功能 | 急停:拍下 -SF9 → 輸送帶停止(類別 0) | 2 |
| 查 PLr | 捲入輥輪=重傷 S2;操作員在旁但非頻繁伸手 F1;帶速慢、看得到 P1 → **PLr c**;公司內規一律做到 d → 設計目標 d | 3 |
| 選架構 | Cat 3:急停雙常閉 → 安全繼電器 -KF5 → 雙接觸器 -QA2/-QA3 串聯+EDM | 4、6.1 |
| 抄數據 | 急停鈕 B10d、-KF5 的 PFHd、接觸器 B10d 皆取自廠商 datasheet;操作頻率估每天 1 次 | 5 |
| 算 PL | SISTEMA 建鏈:感測+邏輯+致動 → 得 PL d ≥ PLr | 5、7 |
| 實測 | 拍急停、拔單通道、模擬熔黏、驗復位;記錄入 &QC001 | 7 |

※ 「內規一律做到 d」是台灣廠常見做法:與其每條迴路分開辯論 c 還是 d,不如標準化一套 Cat 3 迴路料件重複使用——料號統一、庫存共用、畫圖抄範本,貴一點的料換來整廠一致。

## 8.2 情境二:客戶規範寫 PL d,現有設計怎麼補

老機型:急停單常閉 → 一般繼電器 → 單接觸器。客戶新規範要求急停 PL d,差距分析:

| **現況** | **問題** | **改法** |
|---|---|---|
| 急停單常閉接點 | 單通道,Cat B 等級 | 換雙常閉急停頭(多數急停座直接加裝第二接點塊) |
| 一般繼電器當邏輯 | 無監控、無交叉偵測、接點熔黏無人知 | 換安全繼電器 |
| 單接觸器切斷 | 熔黏即失效 | 加第二顆接觸器串聯,兩顆回授接 EDM |
| 無任何文件 | 無法舉證 | 補 SISTEMA 計算書+實測紀錄 |

改造費用主要是一顆安全繼電器+一顆接觸器+工資;真正花時間的是文件與實測。⚠️ 報價時把「驗證工時」報進去——硬體三小時裝完,舉證文件半天起跳,漏報的都變成自己吸收。

# 9. 常見問答(FAQ)

### Q1:一般繼電器可以當安全繼電器用嗎?

不行。差別不在「耐不耐用」,在「壞掉時的行為」:一般繼電器接點熔黏後外部無從得知,也沒有雙通道比對與交叉短路偵測——它壞掉的樣子是「安靜地失效」。安全繼電器的價值是**把失效變成看得見、擋得住**:不一致就鎖住、熔黏就拒絕復位。價差幾千元,買的是這個行為。

### Q2:PL d 跟 Cat 3 是同一件事嗎?

不是,但常被混著講。Cat 3 是「迴路架構長怎樣」(雙通道+監控),PL d 是「整條鏈算出來的可靠度成績」。Cat 3 是達成 PL d 最常見的路,但 Cat 3 配爛元件(MTTFd 低)算出來可能只有 c;Cat 2 配好元件+夠高 DC 也可能達 d。正確講法:「本迴路採 Cat 3 架構,經計算達 PL d」——兩個詞都要講。

### Q3:安全 PLC 跟一般 PLC 差在哪?可以用一般 PLC 做安全功能嗎?

安全 PLC(黃色那台)內部是雙 CPU 互相比對、自我診斷、輸出帶測試脈波,整台經功能安全認證,安全程式另有防呆(修改留跡、簽章)。一般 PLC 沒有這些:程式當掉時輸出可能維持原狀。!!急停、門聯鎖等安全功能不得用一般 PLC 的程式實現——一般 PLC 只能「順便知道」安全動作發生了(拿安全繼電器的輔助接點進 PLC 做顯示、記錄),切斷這件事必須由安全繼電器/安全 PLC 的硬體迴路完成。!!

### Q4:買了 PL e 的光柵,我的迴路就是 PL e?

不是。PL e 是那支光柵「單品的能力上限」;整條鏈=光柵+邏輯+接觸器,由最弱一環決定。光柵 PL e+安全繼電器 PL e+單顆一般接觸器,整條鏈可能只剩 c。型錄上的 PL 是「食材等級」,整桌菜的等級要用 SISTEMA 把整條鏈算完才知道。

### Q5:13849 跟 62061 要不要兩套都做?客戶指定 SIL 怎麼辦?

擇一即可(1.2 節)。機械業用 13849 做到底;客戶規範寫 SIL 2,依對照表以 PL d 設計並在文件中註明對應關係,合約階段先取得客戶同意。兩套都做只會產生兩份要同步維護的文件,沒有安全效益。

### Q6:舊機台從來沒算過 PL,現在要補嗎?

觸發點通常是:改造、事故、客戶稽核、輸歐 CE。原則與第五部改造題相同——動到的安全功能依現行標準補齊(含計算與實測);沒動的部分至少做風險盤點,確認沒有「明顯不足」(例:急停接一般繼電器)。補證據的順序:先補「迴路本身正確」(硬體),再補文件——反過來就是做假帳。

# 10. 常見踩坑總整理

🚫 全冊地雷合輯——左欄看到自己的影子,就翻回對應章節:

| **錯誤做法** | **會發生什麼** | **正確做法** |
|---|---|---|
| 急停只接一個常閉接點進一般繼電器 | 接點氧化/斷線即整條急停失效,且無人知道 | 雙常閉+安全繼電器(Cat 3,見 6.1) |
| 兩顆接觸器省成一顆 | 熔黏即急停失效,單一故障=事故 | 主迴路雙接觸器串聯+EDM 回授 |
| 回授(EDM)端子直接短接 | 熔黏偵測全失效,還能正常復位,假象「都正常」 | 回授照圖接強制導向常閉接點,嚴禁跳線 |
| 安全門用一般極限開關 | 彈簧疲勞/熔黏時門開訊號仍閉合 | 直接開路動作安全開關或 RFID 編碼式 |
| 安全停機寫在一般 PLC 程式裡 | PLC 當機/程式被改,安全功能無聲消失 | 安全功能走安全繼電器/安全 PLC 硬體迴路 |
| 復位迴路接成上電自動復位 | 停電復電、旋開急停瞬間機器自起動 | 手動監控復位(按下-放開邊緣有效) |
| 雙通道兩條線同走一條多芯電纜且無偵測 | 電纜被壓破一次短接兩通道,雙通道變單通道 | 分開佈線,或用具交叉短路偵測的安全繼電器 |
| 光柵距離憑感覺裝 | 手比機器快,遮光了仍搆到危險點 | 實測總停止時間,依安全距離公式計算安裝位置 |
| 選型只看 Cat 不看 MTTFd/DC | Cat 3 配爛料算出 PL c,舉證時翻車 | 用 SISTEMA+廠商數據把整條鏈算完 |
| 只交計算書不做實測(或反之) | 帳面合格、實機接錯;或實機會動、無法舉證 | 計算書+逐一觸發實測,兩張證據都要 |
| 調機時跳線旁路安全裝置,調完忘拆 | 機器帶著被拆保險的迴路投產 | 旁路須申請、掛牌、限時,恢復後重測該功能 |
| 換安全元件後不重算不重測 | 文件與實機脫鉤,證據失效 | 改動即重算受影響鏈+重測該功能(第 7 章) |

!!調機旁路(bypass)安全裝置必須有管制:申請、掛牌、專人限時,調完立即恢復並實測——事故統計裡「忘了拆的跳線」殺的人,不比沒裝安全裝置的少。!!
