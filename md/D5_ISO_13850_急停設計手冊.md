# 1. 前言

## 1.1 13850 管什麼:急停的「功能與人因」

![急停按鈕](images/qet-estop.svg)

先講白話版:急停(現場稱 EMS 或 E-Stop)人人都認得——紅蘑菇、黃底座,出事就拍下去。但「認得」和「設計對」是兩回事。ISO 13850 管的就是急停的**功能與人因設計**,一句話拆成三個問題:

- **裝哪裡?**——每個操作站都要有?輸送帶那麼長怎麼辦?會不會被料架擋住?
- **長怎樣?**——為什麼一定要紅蘑菇黃底?加個保護蓋防誤觸可以嗎?
- **按下去要發生什麼?**——停哪些東西?停到什麼程度?旋開之後機器可以自己動嗎?

這三個問題答錯任何一個,那顆按鈕就只是「長得像急停的裝飾品」。緊急時人的動作是本能反應——手往紅色拍下去——13850 的每一條要求,都是為了讓這個本能反應**一定成功**。

## 1.2 鐵三角分工:13850、60204-1、13849

急停要合格,三本標準缺一不可,分工像蓋房子:

| **標準** | **管什麼** | **白話比喻** |
|---|---|---|
| ISO 13850 | 急停的功能與人因:裝哪、長怎樣、行為邏輯 | 建築設計:門開在哪、多大、往哪個方向開 |
| IEC 60204-1 | 電氣實作:接點型式、迴路接法、顏色細節 | 施工規範:門用什麼五金、怎麼安裝 |
| ISO 13849-1 | 迴路可靠度:PL 等級、要不要雙迴路與監視 | 結構計算:這扇門承受幾次撞擊不會壞 |

⚠️ 三本都要做。急停「長相與位置」對了(13850)、「接線」對了(60204-1),但迴路可靠度沒算(13849-1),風險高的機台一樣不合格——反過來也一樣。

## 1.3 與第五部(D1)的分工

本系列第五部(IEC 60204-1 手冊)第 5.3 節已經講過急停的**電氣接線要求**:常閉接點的失效導向邏輯、直接開路動作的機構原理、STO 與停止類別的迴路實作。本部不重複,聚焦 13850 的主場——**功能行為、外觀人因、佈置與分區**。看到電氣細節請回查 D1 第 5.2/5.3 節,兩本對照著讀,急停這題才算完整。

# 2. 急停的定位:補充性保護措施

這是整本 13850 最容易被誤解、也最重要的一條:

!!急停是「補充性保護措施」(complementary protective measure),不是防護裝置——設計不能靠急停達成安全,護罩與聯鎖才是主角。!!

白話拆解:機械安全的防護有先後順序,像防火一樣——先做防火建材(本質安全設計)、再做防火門(護罩、聯鎖),滅火器(急停)是前面都擋不住時的**最後補救**。你不會因為走廊掛了滅火器,就允許用易燃材料裝潢;同理:

- 🚫 不可以說「這個捲入點沒加護罩,反正旁邊有急停」——急停要靠**人發現危險、人跑過去、人拍下去**,每一環都可能來不及。護罩是不用人反應的,急停是要人反應的,後者永遠不能替代前者。
- 急停的存在前提是:「即使所有防護都做了,仍可能出現非預期狀況」——有人被夾住了、機構飛出異物了、程式失控了——這時需要一個**任何人都能立刻使用**的總煞車。

==風險評估裡不能把急停算成降低風險的手段:風險是靠護罩、聯鎖、安全距離降下來的,急停是額外加上去的保命索。==

💡 換句話說:一台機器「沒有急停」是缺失,「只靠急停」是更大的缺失。

# 3. 功能要求:按下去要發生什麼

## 3.1 立即動作、優先於一切

急停一被觸動,停止命令必須**立即**發出,且**優先於一切其他功能與操作模式**:

- 自動模式、手動模式、教導模式、程式跑到一半——通通無效化,急停說了算。
- 不得有任何「條件判斷」擋在中間:不能設計成「程式先存檔再停」「等這個動作跑完再停」。緊急的意思就是**現在、馬上**。
- 急停也不得被任何起動命令蓋過:急停按著的狀態下,按起動鈕必須沒有反應。

※ 「立即」不等於「瞬間全斷電」——大慣量負載受控煞停(類別 1)也是立即動作,重點是停止**命令**即刻生效、過程不被打斷。類別怎麼選見下一節與 D1 情境 9.2。

## 3.2 停止類別只能 0 或 1

停止類別的定義在 D1 第 5.2 節,這裡只講 13850 的鐵律:

!!急停只能用停止類別 0(立即斷能)或類別 1(受控煞停後斷能),不可用類別 2——因為類別 2 停止後動力仍然保持,人靠近時機器隨時可能再動。!!

| **類別** | **白話** | **可否當急停** |
|---|---|---|
| 0 | 立即切斷動力,像拔插頭 | 可(小慣量首選) |
| 1 | 先受控煞車、停妥後切斷動力 | 可(大慣量首選) |
| 2 | 停了但動力還在,像汽車怠速踩煞車 | 🚫 不可 |

==判斷口訣:急停按下、機器停妥之後,能量必須「已切斷或已耗盡」——還踩著煞車等紅燈的狀態,不叫急停完成。==

## 3.3 自鎖:按下要卡住

急停裝置必須**自鎖**(latching):拍下去要機械性卡住,停止命令持續保持,直到有人在**該裝置上**用明確動作(旋轉解鎖、拉起,部分型式用鑰匙)解除。

為什麼?事故畫面:急停若是「放手就彈回」的型式,拍急停的人一鬆手、或有人誤碰復位,停止命令就消失了——而被救的人可能還卡在機器裡。==自鎖的意義:停止狀態的解除權,留在按下那顆按鈕的位置,由人刻意執行,不會自己消失。==

⚠️ 選型時注意:市面上有外觀神似急停的「非自鎖蘑菇鈕」,拍下去會彈回——這種**不得**當急停用。訂購時規格要寫明 latching/自保持型式。

## 3.4 解除≠再起動

!!解除急停(旋開/拉起)只是「允許機器再起動」,機器本身不得因此動作——必須有人另外執行起動操作,機器才能動。!!

事故畫面在 D1 第 5.3 節講過:技師排完卡料、旋開急停,機器在旋開瞬間直接起動,人還在圍籬內。這條規則在 13850 與 60204-1 是同一條命換來的共識,兩本都寫、缺一不可:

- 13850 管**行為**:reset(解除)與 restart(再起動)必須是兩個獨立動作;
- 60204-1 管**接線**:迴路上如何保證復位訊號不會直接變成起動訊號(見 D1 第 5.4 接地側規則)。

# 4. 人因與外觀:長什麼樣子才叫急停

![蘑菇頭記號](images/mark-mushroom.svg)

急停是給「情急之下的人」用的,外觀規則全部圍繞一個目標:**慌張的人、不熟這台機器的人、甚至戴著手套倒退著撞上去的人,都能成功觸動它。**

==急停操作件必須是紅色、背景(底座環)必須是黃色——紅配黃是急停的專屬色,全廠只有急停能長這樣。==語意在 D1 附錄 A 的顏色語言總表:如果別的按鈕也做紅色、別的底座也塗黃,緊急時操作員就要「想一下」——而急停的設計目標就是**不用想**。

其他人因要求整理成表:

| **要求** | **白話理由** |
|---|---|
| 手掌型(蘑菇頭)、拉繩、腳踏等「粗動作」型式 | 緊急時人是用拍的、撞的、踹的,不是用手指精準點的 |
| 直接操作:一個動作直接觸發,不得經過選單/確認 | 🚫 觸控螢幕上的「急停圖示」不算急停——要滑開、要按確認、螢幕當機就沒了 |
| 不得需要工具才能操作 | 要先找鑰匙、開蓋子才能按的,不叫緊急裝置 |
| 任何方向接近都容易觸動 | 蘑菇頭凸出於面板,倒退撞上也會觸發 |
| 操作力適中 | 太重按不下去;但也要能抵抗輕微碰觸誤動作(見第 7 節防誤觸) |

💡 為什麼觸控螢幕不行?急停要求「直接操作原則」——機械動作直接打開接點,不經過軟體。螢幕死機、程式當掉、通訊斷線,實體蘑菇鈕都還能動作;軟體急停在最需要它的時刻最不可靠。HMI 上可以放「停止」鈕,但那是一般停止,不是急停。

# 5. 佈置原則:裝在哪裡、裝幾顆

## 5.1 每個操作站都要有

原則一句話:**人在哪裡操作,急停就要在哪裡伸手可及。**

- 每個操作站(主操作面板、給料口、出料口、遙控器/教導器)都要有急停;
- 沿著操作人員的**作業行程**檢查:他走到哪、手搆得到嗎?不能要求人「跑回主面板」才能拍急停——跑過去的三秒鐘,就是手套被捲進滾輪的三秒鐘;
- ==急停不可被遮擋:料架、堆料、開啟的門板、後加裝的設備,都不能擋在急停前面==——設計時對、現場擺一個棧板就不對了,這條要寫進日常巡檢;
- 維修、清潔、排障常去的位置(機構背面、盤後走道)也要納入評估——會有人出現的地方,就可能有人需要急停。

## 5.2 急停鏈:按任何一顆都要全停

一台設備裝了多顆急停,規則只有一條:

!!同一台設備上的任何一顆急停被按下,整台設備都必須停止——不允許「這顆只停這一段」的模糊地帶(分區急停是例外,見第 6 節,但有嚴格的標示條件)。!!

現場稱這條串起來的迴路為「急停鏈」:所有急停裝置的常閉接點串聯進同一條安全迴路,任何一顆打開,整條鏈斷開、全機停止。接線細節見 D1 第 5.3 節,這裡記住行為:==拍的人不需要知道自己拍的是哪一顆——任何一顆,效果都一樣。==

⚠️ 驗收時要**逐顆實測**,不是測一顆代表全部——沒測到的那顆可能根本沒接進鏈裡(D1 第 8 章的功能測試同樣要求)。

## 5.3 變形:觸繩開關與腳踏急停

蘑菇鈕不是唯一型式,場合不同、型式不同:

| **型式** | **適用場合** | **設計重點** |
|---|---|---|
| 觸繩開關(rope pull,現場稱拉繩開關) | 輸送帶等長距離設備——不可能每兩公尺裝一顆按鈕 | 沿線任一點拉動即觸發;==鋼繩斷裂或鬆弛時開關也必須動作(斷繩=觸發,不是斷繩=失效)==;張力要定期檢查 |
| 腳踏急停 | 雙手被佔用的工位(雙手抱料、雙手在治具上) | 防止無意踩踏的外型設計,但不得妨礙緊急踩下 |
| 急停把手/掌壓桿 | 大面積需要「撞上去就停」的位置 | 任意方向施力均能觸發 |

※ 觸繩開關的復位在開關本體上操作,和按鈕同理:誰拉的繩,要回到那個開關上復位,拉直繩子不等於復位。

# 6. 分區急停(span of control)

大型產線幾十公尺、十幾個工作站,「按一顆全線停」有時反而製造危險(全線急停導致在製品互撞、上游堆料)。13850 允許**分區急停**——一顆急停只管一個區段(span of control,控制範圍)——但條件嚴格:

- **分區必須來自風險評估**,不是為了「少停一點產量」而分——分區的理由只能是安全,不能是產能;
- !!每顆急停「管到哪一區」必須在裝置處清楚標示,讓按的人一看就知道範圍——最危險的誤解就是「以為全停了,其實只停了半條線」。!!
- 分區之間若有能量或物料會互相影響(A 區停了,B 區的料還往 A 區送),分區邊界就劃錯了——==分區的邊界必須是「這一區停下後,區內的人真的安全」的邊界==;
- 同一區內仍然適用第 5.2 節:區內任何一顆急停,整區全停。

💡 標示怎麼做才算「清楚」?圖示+文字標明範圍(例:「急停|本按鈕停止:3 號組裝站全區」),配平面示意圖更好;而且全線各站的標示邏輯要一致——有的站管全線、有的站管半區、標示又不清楚,等於埋地雷。拿不準就不要分區:**全線停,永遠是安全的預設值。**

# 7. 裝置選型細節

![常閉接點](images/qet-contact-nc.svg)

選型三件事,原理在 D1 第 5.3 節講透了,這裡整理成採購檢查表:

| **項目** | **要求** | **一句話理由** |
|---|---|---|
| 接點型式 | 常閉(NC),一般用**雙常閉**進安全繼電器 | 斷線即停、故障自暴露;雙迴路互為備援並供監視(可靠度等級依 ISO 13849-1) |
| 動作機構 | 直接開路動作(positive opening,型錄符號⊖,又稱強制斷開) | 接點熔黏也會被機械行程硬掰開——急停不允許「按了卻沒斷」 |
| 保持機構 | 自鎖(latching),旋轉/拉起復位 | 見第 3.3 節:停止命令不得自己消失 |

選型時認明型錄上的⊖符號與「EN ISO 13850 / IEC 60947-5-5 適用」字樣——長得像蘑菇的按鈕不一定是合格的急停元件。

**防誤觸的正確姿勢:**產線常有急停被手肘、料箱誤撞的困擾,直覺反應是加保護蓋——小心,方向錯了:

- 🚫 加了蓋子、圍了護框,導致緊急時要「先開蓋再按」——這違反「不得需要額外動作/工具」原則,防了誤觸、也防了救命;
- 正確做法:改用**防護環(guard collar)不高於蘑菇頭頂面**的型式、調整安裝位置避開通道擦撞線、或改凹型底座——==防誤觸的底線:任何防護造型都不得妨礙一掌拍下。==

# 8. 實務情境範例

## 8.1 情境一:改機加了新工作站,忘了急停

**背景:**包裝線尾端加裝一台自動貼標機(現場說法:改機)。機構、電控都接好了,貼標機的動力串進原產線的主電源,試車正常,驗收文件也簽了。

**三個月後:**貼標站操作員的袖口被輸送夾點勾住。她伸手要拍急停——最近的一顆在五公尺外的原產線操作站,中間隔著料架。同事聽到叫聲跑過去拍停,袖子已經扯裂,幸而人只有擦傷。

**檢討,每一條都對應本手冊:**

| **缺失** | **對應章節** |
|---|---|
| 新工作站是新的「操作站」,卻沒有配急停 | 5.1 每個操作站都要有 |
| 原有急停被後來擺放的料架遮擋 | 5.1 不可被遮擋 |
| 貼標機動力有沒有接進原急停鏈?驗收沒測 | 5.2 急停鏈逐顆實測 |

==改機的鐵則:機器的範圍變了,急停的佈置評估就要重做——「加一站」不是只加動力和訊號,是加一個「有人的地方」。==驗收清單見附錄 A。

## 8.2 情境二:「我以為整條線都停了」

**背景:**三十米組裝線,依風險評估分成三區急停,設計上合理。但現場標示只有一張褪色貼紙,新進員工訓練也沒講分區。

**事發:**2 區員工發現 3 區有同事的工具袋被治具勾住、人正探身去拉。他拍下手邊(2 區)的急停,看到眼前輸送帶停了,大喊「停了!你拉!」——但 3 區根本沒停,治具繼續前進。同事及時鬆手,工具袋被絞進去。

**檢討:**分區設計本身合規,敗在**標示與訓練**——按的人不知道自己按的那顆管到哪裡,還把「眼前停了」誤讀成「全線停了」。這正是第 6 節鐵律的事故版本:==分區急停的每一顆按鈕,都必須讓按的人「一看就知道停哪裡」;做不到清楚標示,就退回全線停。==

🚫 順帶一個常見錯誤:有人建議「那就教育訓練講清楚就好,標示不用改」——不行。急停的使用者包含訪客、外包商、剛報到的人,人因設計的原則是**不依賴記憶與訓練**,標示必須在裝置上、在現場、在當下可讀。

# 9. 常見問答(FAQ)

### Q1:急停跟一般停止鈕差在哪?我平常按「停止」不也停了?

行為等級完全不同。一般停止:依程式流程停(可能跑完這個循環才停)、可以是類別 2、外觀不限。急停:立即、優先於一切、只能類別 0/1、自鎖保持、紅蘑菇黃底、直接開路接點。一句話:**停止是「請機器停」,急停是「命令機器立刻停,不聽任何解釋」。**

### Q2:急停可以拿來當日常停機用嗎?下班拍一下很方便。

🚫 不建議,多數廠規直接禁止。理由:(1)急停通常是類別 0 直接斷能,對變頻器、伺服與機構是粗暴停法,天天拍等於天天小型撞擊;(2)急停元件的設計壽命是「偶爾使用」,當日常開關用會提早磨耗——真正緊急那天可能就是它失效那天;(3)天天拍急停,警覺性會麻痺,「急停被按下」不再是異常訊號。日常停機請用正常停止程序,下班斷電請用主開關(見 D1 第 2 章)。

### Q3:拉繩(觸繩開關)要多久測一次?

依廠內 SOP 與製造商說明,常見做法:每班/每日目視(繩有無鬆弛、勾掛異物)、定期(例如每月)實際拉動測試沿線多點觸發、並測「斷繩/鬆弛也會觸發」這個保護行為。張力會隨溫度與時間漂移,==觸繩開關是「會鬆掉的急停」,不定期測就等於沒有。==測試紀錄留存,驗收與稽核都會查。

### Q4:遙控器/無線教導器上的急停,和機台上的一樣嗎?

功能要求一樣(立即、優先、自鎖),但多一個課題:無線鏈路斷線時怎麼辦——標準要求通訊失效時設備必須進入安全狀態(等效於停止)。另外注意:遙控器離開現場、電池沒電時,它上面那顆急停就「不存在」了,機台本體的急停佈置不能因為遙控器有急停而縮水。

### Q5:急停按下後,氣壓缸掉下來砸東西,這樣對嗎?

不對,而且是選類別時的典型考題。急停的目標是「最快到達**安全狀態**」——垂直軸、夾持中的工件,斷能瞬間可能因重力掉落或鬆脫,反而製造新危險。這類軸要搭配機械抱閘、止回閥或選類別 1 受控停止,停妥後再斷能。設計時把「斷能之後會發生什麼」逐軸想一遍,見附錄 A 檢查清單。

### Q6:急停迴路要做到什麼 PL 等級?

這題不歸 13850 管——迴路可靠度(PL/SIL、單雙迴路、監視)是 ISO 13849-1 依風險評估決定的,常見急停做到 PL c~e 不等。分工表見第 1.2 節:13850 告訴你急停「該長怎樣、該做什麼」,13849-1 告訴你「迴路要多可靠」。

# 10. 常見踩坑總整理

| **錯誤做法** | **會發生什麼** | **正確做法** |
|---|---|---|
| 「這裡沒護罩,反正有急停」 | 急停要人反應,來不及就是來不及;風險評估不過關 | 護罩/聯鎖先做好,急停只當補充措施 |
| 用類別 2 停止當急停 | 停止後動力仍在,人靠近時誤動作 | 急停只能類別 0 或 1,停妥後斷能 |
| 用非自鎖蘑菇鈕當急停 | 一鬆手停止命令消失,救援中機器恢復 | 選 latching 自鎖型,旋開/拉起才復位 |
| HMI 觸控畫面放「急停」圖示充當急停 | 螢幕當機/程式掛掉時按不了 | 實體裝置直接操作;HMI 只能放一般停止 |
| 旋開急停機器直接恢復運轉 | 人還在危險區內,復位瞬間被夾 | 復位只是允許再起動,須另按起動鈕 |
| 急停加保護蓋防誤觸 | 緊急時要先開蓋,慢一步就是一隻手 | 防護環不高於鈕頂、調整位置,不得妨礙拍下 |
| 改機加站沒有重新評估急停佈置 | 新工作站的人搆不到任何急停 | 機器範圍改變即重做佈置評估並實測 |
| 分區急停沒有標示控制範圍 | 「以為全停了其實只停半條線」 | 每顆裝置標明管轄範圍;標不清楚就全線停 |
| 多顆急停驗收只實測一顆 | 沒接進急停鏈的那顆現場才被發現 | 逐顆實測,含復位不自行再起動 |
| 觸繩開關裝好後從不檢查張力 | 繩鬆弛拉不動、或誤觸發頻繁被人為旁路 | 依 SOP 定期拉動測試與張力檢查並記錄 |
| 急停前方堆料、被門板/料架遮擋 | 設計合格、現場不可用 | 急停淨空納入日常巡檢與 5S |
| 紅蘑菇鈕拿來當一般啟閉開關 | 元件磨耗+全廠紅黃語意混亂 | 紅配黃專屬急停;日常停機用正常程序 |

# 附錄 A:急停檢查清單(設計/驗收)

| **檢查項目** | **設計階段** | **驗收階段** |
|---|---|---|
| 風險評估中急停列為補充措施,未替代護罩/聯鎖 | 確認評估文件 | 抽查對照現場防護 |
| 停止類別選定 0 或 1,逐軸確認斷能後無重力/殘壓危險 | 逐軸列表 | 實測停止行為與停後狀態 |
| 每個操作站(含遙控器、維修位置)皆有急停 | 佈置圖標註 | 現場走一圈逐站確認 |
| 行程內伸手可及、無遮擋 | 檢視作業動線 | 實地模擬操作員位置 |
| 紅蘑菇+黃底,全機無其他紅黃混用 | 選型與面板圖 | 目視全機 |
| 自鎖型式,復位動作明確 | 型錄確認 latching | 逐顆拍下/復位實測 |
| 雙常閉+直接開路動作(⊖),接入安全迴路 | 型錄與迴路圖(併 D1 5.3) | 迴路測試與斷線測試 |
| 任何一顆急停→全機(或標示區)停止 | 急停鏈圖面 | 逐顆實測範圍 |
| 復位≠再起動 | 迴路設計確認 | 每顆復位後驗證機器不自行動作 |
| 分區急停:分區依據+每顆標示控制範圍 | 風險評估+標示圖 | 標示可讀性+實測各區範圍 |
| 觸繩:沿線多點觸發、斷繩/鬆弛即觸發 | 選型與張力計算 | 多點拉動+模擬鬆弛測試 |
| 防誤觸措施不妨礙操作 | 造型審查 | 戴手套單掌實拍 |
| 標示、測試週期寫入操作/維護文件 | 文件清單 | 抽查 SOP 與紀錄表單 |

※ 驗收欄的精神只有一句:**每一顆、每一區、每一個行為,實際動手測,不用文件代替現場。**
