# 1. 前言

## 1.1 本冊的定位:盤體作為「一個產品」

前九冊講「圖怎麼畫、元件怎麼命名」。本冊換一個視角:當你組好一面盤、要出貨給客戶時,==這面盤本身就是一個產品,要能證明它安全==——溫升不超標、短路時撐得住、人碰不到帶電部分。這套「盤體產品規格與驗證」的規則就是 IEC 61439。

它和製圖沒有直接關係(本冊也因此**不列入線上檢定**),但盤廠實務天天遇到:客戶規範要求「盤體依 IEC 61439-2 製造並提供驗證報告」,驗收時追問溫升報告、短路等級、銘牌內容——本冊讓你看懂這些要求在說什麼、責任落在誰身上。

## 1.2 系列結構:61439 家族

| 部 | 對象 | 常見場合 |
|---|---|---|
| 61439-1 | 通則(單獨引用無效,必須配產品部) | 各部的共同規則來源 |
| 61439-2 | 動力開關設備成套(PSC) | ==工業配電盤、MCC、控制中心——盤廠主戰場== |
| 61439-3 | 一般人員可操作的配電箱(DBO) | 建築分電箱 |
| 61439-4 | 工地用成套(ACS) | 臨時電盤 |
| 61439-5 | 公共配電網成套 | 台電低壓配電箱 |
| 61439-6 | 母線幹線系統(BTS) | 母線槽 |
| 61439-7 | 特定場所(碼頭、露營地、EV 充電) | 充電樁配電 |

引用時一律「-1 + 產品部」:工業盤=61439-1+-2。前身是 IEC 60439 系列(2009 起改版換號),舊規範書寫 60439 時對應閱讀即可。

## 1.3 最重要的判斷:60204-1 還是 61439?

這是盤廠最常混淆的問題,判斷原則:

- ==裝在機器上、屬於機器電氣設備的控制盤 → IEC 60204-1==(機械指令的世界,第五部手冊)。
- ==獨立的配電盤、MCC、對外供電的成套設備 → IEC 61439==(低電壓指令 LVD 的世界)。
- **混合情況**(機台盤內含大型配電段;或一面盤同時配電+控制多台機器):功能導向拆分——配電功能段依 61439 驗證,機器控制功能依 60204-1;合約與技術文件寫明各段的依據。

實務速判:問「這面盤跟著機器 CE 還是自己 CE?」跟機器走=60204-1 為主;盤單獨出貨、單獨掛 CE=61439。詳見附錄 A。

# 2. 兩種製造商:責任怎麼分

61439 的核心制度設計,是把責任拆給兩個角色:

## 2.1 原始製造商(original manufacturer)

完成**設計驗證**的一方——通常是盤體系統的品牌商(如施耐德 Prisma、ABB、威圖的盤體系統):他們做過溫升、短路、耐壓等全套驗證,發行「已驗證系統」的型錄與組裝規則。

## 2.2 成套製造商(assembly manufacturer)

按已驗證系統**組裝出貨**的一方——多數盤廠的角色。責任:

- 遵守原始製造商的組裝規則(元件選用、排列、扭力、隔間)。

- 做每台出廠的**例行檢驗**(第 5 章)。

- 掛自己的銘牌:==對客戶而言,成套製造商就是這面盤的製造者,承擔產品責任==。

## 2.3 「偏離型錄」的代價

只要偏離已驗證系統——換非認可元件、改母線排列、加大密度——==偏離的部分,設計驗證的責任就轉移到你身上==:你得自己用試驗/計算/比對證明(第 4.1 節)。「照型錄組裝」與「自行設計」的合規成本天差地遠,報價前先弄清楚案子屬於哪種。

# 3. 額定值:銘牌上的數字

## 3.1 電壓類額定

| 符號 | 名稱 | 意義 |
|---|---|---|
| Un | 額定電壓 | 成套設備的標稱系統電壓 |
| Ue | 額定操作電壓 | 迴路層級的工作電壓 |
| Ui | 額定絕緣電壓 | 絕緣設計基準(≥Ue) |
| Uimp | 額定衝擊耐受電壓 | 承受雷擊/開關突波的能力 |

## 3.2 電流類額定

| 符號 | 名稱 | 意義 |
|---|---|---|
| InA | 成套設備額定電流 | 整盤能連續承載的電流 |
| Inc | 迴路額定電流 | 單一迴路能連續承載的電流 |

額定電流的本質是**溫升限制**:不是元件框架電流的加總,而是「在這個箱體、這種排列、這個環境溫度下,持續通這麼多電流溫升不超標」。

## 3.3 短路類額定

| 符號 | 名稱 | 意義 |
|---|---|---|
| Icw | 額定短時耐受電流 | 撐過短路電流的能力(有效值+時間,如 25 kA/1 s) |
| Ipk | 額定峰值耐受電流 | 承受第一波峰值電磁力的能力 |
| Icc | 額定條件短路電流 | 搭配指定保護器件時的短路能力 |

客戶規範寫「短路等級 25 kA」時,追問清楚是 Icw 還是 Icc——==Icc 靠上游保護器件限流,換掉那顆斷路器,短路能力就不成立==。

## 3.4 需求係數 RDF

RDF(rated diversity factor):考慮各迴路不會同時滿載,「所有出線迴路可同時通額定電流的比例」。例:10 路各 100 A、RDF 0.6=同時通電總量以 600 A 驗證。==看盤體額定時一定連 RDF 一起看==——InA 800 A/RDF 0.5 與 InA 400 A/RDF 1.0 的實際能力可能相同。

# 4. 設計驗證(design verification)

## 4.1 三種驗證途徑

61439 允許三種方式證明設計合格,可逐項混用:

| 途徑 | 做法 | 適用 |
|---|---|---|
| 試驗(testing) | 實體樣品做型式試驗 | 最強證據;原始製造商的系統驗證 |
| 比對(comparison) | 與已試驗的參考設計比對 | 衍生設計(小改) |
| 評估(assessment) | 計算/設計規則推導 | 溫升(小電流)、間隙爬電等可計算項 |

## 4.2 驗證項目總表

| 驗證項目 | 驗的是什麼 |
|---|---|
| 材料與零件強度 | 耐腐蝕、耐熱、耐燃、UV |
| 外殼防護等級 | IP(防塵防水)、IK(耐衝擊) |
| 電氣間隙與爬電距離 | 帶電部之間、對地的絕緣距離 |
| 電擊防護與保護迴路 | PE 連續性與短路下的保護迴路耐受 |
| 器具與導體的安裝 | 元件與配線依規則安裝 |
| 內部迴路與連接 | 母線與分支的載流與固定 |
| 外部導體端子 | 端子適配外部電纜 |
| 介電性能 | 工頻耐壓+衝擊耐壓 |
| ==溫升== | 額定電流下各部位溫升不超限 |
| ==短路耐受== | Icw/Ipk/Icc |
| EMC | 電磁相容 |
| 機械操作 | 操作機構壽命 |

## 4.3 溫升:最常見的地雷

盤體驗證出問題,八成在溫升。設計端的實務要點:

- 額定電流由「箱體+排列+環境」決定,==元件目錄值是敞開環境的數字,裝進箱體要降容==(原始製造商型錄有降容表)。

- 高密度排列、頂部裝發熱元件(變頻器)、加門封 IP 提升,都會吃掉溫升裕度;風扇/散熱設計改變=偏離已驗證系統。

- 環境溫度基準:61439 預設日平均 35°C;現場更熱(頂樓機房)要再降容。

## 4.4 短路耐受

- 短路時母線承受巨大電磁力(正比於電流平方),==母線支撐間距是短路驗證的一部分,不是隨意可改的機構細節==。

- 依已驗證系統組裝時,支撐間距、螺栓扭力照型錄;縮短間距可以,加大間距=偏離。

- 上游保護器件的限流特性可成就 Icc——文件與銘牌要載明搭配條件。

# 5. 例行檢驗(routine verification)

## 5.1 每一台出廠都要做

設計驗證證明「這種設計」安全;例行檢驗證明「這一台」組裝無誤。==例行檢驗是成套製造商跑不掉的責任,每台都做、留下紀錄==,報告是交機文件的一部分。

## 5.2 檢驗項目

| 類別 | 項目 |
|---|---|
| 結構 | 外殼防護/間隙爬電抽查、標示與銘牌、內部檢視(扭力、配線、隔間) |
| 性能 | 配線正確性與功能測試、==PE 保護迴路連續性==、絕緣電阻或工頻耐壓 |

與 60204-1 的驗證測試(第五部手冊)高度重疊——同一台盤兩邊都適用時,測試做一次、報告分別對應兩標準的條文即可。

# 6. 與製圖體系的銜接

## 6.1 盤體文件的 DCC 與代號

61439 要求成套設備交付技術文件——而文件怎麼編,就回到本系列的主軸:

- 迴路圖 &EFS、佈置圖 &ELU、端子圖 &EMA、驗證報告與出廠檢驗紀錄(品質類文件)——DCC 依第三部手冊。

- 盤內元件代號依 81346(第一、二部);盤體本身就是位置面向的節點(+A1)。

## 6.2 銘牌與標示

銘牌必載:成套製造商名稱、型式/識別編號、製造日期、適用標準(IEC 61439-2)、電流/電壓/短路等額定(第 3 章)、IP 等級、重量(大盤)。==銘牌上的每個數字都要有驗證文件支撐==——寫得出 25 kA,就要拿得出 25 kA 的依據。

# 7. 實務情境範例

**情境一:客戶規範一句話拆解。**「配電盤依 IEC 61439-2 設計製造,短路等級 50 kA/1s,提供型式試驗報告與出廠檢驗報告。」解讀:Icw 50 kA(不是 Icc)→ 需要已驗證系統本身達 50 kA;型式試驗報告=原始製造商的系統驗證文件(跟品牌商索取)+你的組裝符合性聲明;出廠檢驗報告=你自己做的例行檢驗(第 5 章)。報價前確認品牌系統等級,50 kA 與 25 kA 的系統成本差很多。

**情境二:機台盤還是配電盤?**一面盤:上段 400 A 進線與分路斷路器供三台機器,下段是其中一台機器的控制迴路。判斷:上段配電功能=61439-2 範圍;下段機器控制=60204-1 範圍。文件寫法:盤體整體依 61439-2 驗證(溫升/短路以全盤計),控制段的急停、線色、I/O 依 60204-1;兩份標準都列在技術文件首頁。

**情境三:換一顆「等效」元件。**已驗證系統指定 A 牌斷路器,採購想換便宜的 B 牌「規格相同」。後果:這是偏離已驗證系統——該迴路的溫升與短路驗證失效,你得自行證明(通常做不起試驗)。正解:回到原始製造商的認可元件清單選替代品,或要求客戶接受變更並重新評估。==「規格相同」不等於「驗證仍有效」==。

# 8. 常見問答(FAQ)

### Q1:我們做機台控制盤,61439 跟我們有關嗎?

多數時候 60204-1 就夠。但兩種情況會碰到:盤內含較大的配電功能段;或客戶規範直接指名 61439。看懂本冊,至少知道對方在要什麼、哪些是原始製造商該給的。

### Q2:61439 有規定怎麼畫圖嗎?

沒有。它引用 TC3 體系(61082/81346/61355)要求「提供技術文件」,畫法回到本系列一~九冊——這也是本冊不列入檢定的原因:它是產品驗證規範,不是製圖規範。

### Q3:「型式試驗過的盤」現在還這樣講嗎?

舊 60439 的 TTA/PTTA(型式試驗/部分型式試驗)分類已廢;61439 改為「設計驗證」概念,且明確允許試驗以外的比對與評估途徑。聽到 TTA 就知道對方在講舊制。

### Q4:例行檢驗的耐壓測試會不會打壞元件?

依標準選擇工頻耐壓或絕緣電阻量測;含電子元件(變頻器、電源)的迴路依製造商指示斷開或旁路後再測——這與 60204-1 驗證測試的注意事項相同(第五部手冊)。

### Q5:台灣案子也用 61439 嗎?

台灣法規體系(CNS)對應翻採 IEC 61439(CNS 15591 系列);出口與外商案普遍直接引用 IEC。合約寫哪個版本就依哪個版本,概念完全相同。
