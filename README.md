# IEC-Learning｜IEC 電氣製圖規範學習網

一個為初學者打造的教學專案，用比較「人話」的方式，帶你了解如何運用 IEC 國際規範進行電氣繪圖與識圖。

> 姊妹專案：[HappyLearnCodesys](https://github.com/jolinjo/HappyLearnCodesys) — 本專案的網站架構將參考其設計。

## 為什麼要做這個？

IEC 規範原文又厚又硬，初學者常常不知道從哪裡下手：

- 畫一張電路圖，圖框、線號、符號到底該怎麼標？（IEC 61082-1）
- 設備和元件的代號 `=`、`+`、`-` 是什麼意思？怎麼編？（IEC 81346）
- 文件編號怎麼分類、怎麼查？（IEC 61355）
- 機械電氣設計有哪些安全與配線的基本要求？（IEC 60204-1）

本專案把這些規範的核心概念萃取出來，整理成有學習路線的中文教材，讓你能「看懂圖、畫對圖」。

## 教學網站

網站以 Next.js（App Router）+ TypeScript + Tailwind CSS 建置，靜態輸出部署到 GitHub Pages（push 到 main 自動部署）。

- **學習路徑**：入門（看懂符號與代號）→ 進階（讀懂一整套圖）→ 精通（畫出正規的圖），三階段導讀八冊手冊。
- **線上檢定**：每章 20 題即時考核，答錯立即顯示正解與解析；依弱點主題加權出題；總檢定橫跨全題庫。成績與弱點紀錄保存在瀏覽器本機（localStorage），不上傳。

```bash
npm install
npm run dev    # 本機開發 http://localhost:3000
npm run build  # 靜態輸出到 out/
```

> 首次部署需在 GitHub 儲存庫 Settings → Pages 將 Source 設為「GitHub Actions」。
