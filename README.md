# IEC-Learning｜IEC 電氣製圖規範學習網

一個為初學者打造的教學專案，用比較「人話」的方式，帶你了解如何運用 IEC 國際規範進行電氣繪圖與識圖。

> 姊妹專案：[HappyLearnCodesys](https://github.com/jolinjo/HappyLearnCodesys) — 本專案的網站架構將參考其設計。

## 為什麼要做這個？

IEC 規範原文又厚又硬，初學者常常不知道從哪裡下手：

- 畫一張電路圖，圖框、線號、符號到底該怎麼標？（IEC 61082-1）
- 設備和元件的代號 `=`、`+`、`-` 是什麼意思？怎麼編？（IEC 81346）
- 文件編號怎麼分類、怎麼查？（IEC 61355）
- 機械電氣設計有哪些安全與配線的基本要求？（IEC 60204-1）

本專案把這些規範的核心概念萃取出來，整理成有學習路線的中文教材，讓你能「看懂圖、畫對圖」。

## 專案進行方式

本專案分兩個階段：

1. **內容萃取（進行中）**：逐一討論各規範的核心內容，整理成 `md/` 下的教學手冊文件。
2. **網站建置（規劃中）**：內容穩定後，參考 HappyLearnCodesys 的架構（Next.js App Router + TypeScript + Tailwind CSS，GitHub Pages 靜態部署），將教材做成可搜尋、有學習地圖的教學網站。

## 目錄結構

```
IEC-Learning/
├── md/           # 教學手冊 Markdown(正式版本)
│   └── images/   # 符號圖(由 QET 元件庫轉出的 SVG)
├── doc/          # 手冊的 .docx 原始來源檔
├── tools/        # QET .elmt → SVG 轉換工具
└── README.md
```

網站建置階段展開後，將依序加入 `app/`、`components/`、`content/`、`public/` 等目錄。
